Détection des sections refaite : les sections sont découpées sur le terrain que partagent vos sorties, identiques sur chaque appareil, pour un catalogue stable. Chaque section garde un historique que vous pouvez rétablir, les sections retirées restent listées, et un tour peut être exclu. Widgets d'accueil pour vos stats de forme. Les notifications nomment l'itinéraire et les records dans votre langue. Le moteur se rétablit après une base endommagée sans perdre itinéraires et sections.
